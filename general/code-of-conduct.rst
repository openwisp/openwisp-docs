Code of Conduct
===============

Open source doesn't mean "anything goes". **Be respectful, or be gone**.

.. _anti_spam_policy:

Anti AI Spam Policy
-------------------

.. warning::

    **Abuse of AI tools will lead to a temporary ban without prior
    warning. Repeated violations will lead to a permanent ban.**

AI assistance is permitted in OpenWISP, but contributors must use it
responsibly.

Every contributor is expected to understand, test and explain every change
they submit.

Using AI to engage in spammy behavior, such as posting repetitive or
low-value content in short bursts, places too much burden on maintainers.
It can pressure them to merge code before it is fully understood and
audited, creating a :ref:`supply-chain security risk
<project_publishing_infrastructure>`.

Examples include:

- **Uninvestigated AI-generated issues:** issues generated by AI tools or
  automation without real user impact, meaningful investigation, or
  project understanding;
- **Artificial issue-to-pull-request workflows:** workflows created mainly
  to score contributions rather than solve a validated project need;
- **Unsolicited or unvalidated pull requests:** pull requests without a
  related issue, or targeting issues that have not been opened,
  acknowledged, or :ref:`validated by maintainers
  <openwisp_look_for_open_issues>`;
- **Incomplete, unsafe, or poorly understood pull requests:** pull
  requests that are incomplete, untested, or insecure, or that the
  contributor cannot adequately explain;
- **Excessive automated activity:** repeated pushes, failed CI builds, or
  automated review activity that wastes maintainer time, pressures
  maintainers to merge code before fully reviewing it, or consumes
  excessive CI or automated-review resources;
- **Repeated AI-assisted comments:** substantially similar comments posted
  across multiple issues to ask to work on, reserve, or be assigned an
  issue, even when superficially customized.

When a contribution is closed under this policy, maintainers may provide
only a link to this policy as the explanation.
